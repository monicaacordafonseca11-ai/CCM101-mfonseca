# Client Recommendations & Decision Matrix

## Client Recommendations

### Client A – Startup Company
* **Recommended Platform:** AWS[cite: 1]
* **Justification:** AWS provides flexible pay-as-you-go pricing, generous startup credit programs, and high infrastructure elasticity[cite: 1]. This lets the startup launch with minimal initial costs while remaining fully prepared for rapid growth[cite: 1].
* **Services:** AWS Elastic Beanstalk, Amazon S3, Amazon DynamoDB[cite: 1].

### Client B – University
* **Recommended Platform:** Microsoft Azure[cite: 1]
* **Justification:** The university relies heavily on Active Directory, Windows Server, and Microsoft 365[cite: 1]. Moving to Azure allows seamless identity management via Microsoft Entra ID and cost savings through existing Microsoft licensing benefits[cite: 1].
* **Services:** Microsoft Entra ID, Azure Virtual Machines, Azure Hybrid Benefit[cite: 1].

### Client C – AI Research Company
* **Recommended Platform:** Google Cloud Platform (GCP)[cite: 1]
* **Justification:** GCP offers specialized AI infrastructure, custom TPU hardware, and dedicated data tools like Vertex AI[cite: 1]. This makes it an ideal fit for high-performance computing and machine learning research[cite: 1].
* **Services:** Vertex AI, Google Cloud TPU, Google Cloud Storage[cite: 1].

### Client D – Global E-Commerce Company
* **Recommended Platform:** AWS[cite: 1]
* **Justification:** AWS features a global network infrastructure, multi-region database replication, and reliable auto-scaling systems[cite: 1]. This guarantees high availability and fast performance for online shoppers worldwide during high-traffic spikes[cite: 1].
* **Services:** Amazon CloudFront, Amazon Aurora Global Database, AWS Auto Scaling[cite: 1].

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | AWS | Low upfront costs, rich ecosystem of managed services, and easy scalability[cite: 1]. |

| **Global Web Application** | AWS | Extensive global distribution networks (CloudFront CDN) and edge locations[cite: 1]. |
