# Mission Reflection

Exploring the major public cloud platforms during this laboratory activity has provided valuable insights into modern enterprise infrastructure. Among Amazon Web Services, Microsoft Azure, and Google Cloud Platform, GCP impressed me the most due to its clean developer-centric interface, seamless container management through Google Kubernetes Engine (GKE), and powerful data analytics tools like BigQuery. Its focus on modern application architecture and cutting-edge artificial intelligence models makes it particularly compelling for next-generation development.

Despite their individual strengths, AWS, Azure, and GCP share fundamental architectural similarities. All three providers offer core services covering compute virtual machines, object storage buckets, software-defined networking, and role-based Identity and Access Management (IAM) security policies. Recognizing these functional equivalents made it clear that while service names and management interfaces differ, the underlying principles of cloud computing remain consistent across platforms.

This activity demonstrated how strongly business requirements dictate cloud platform choices. Technical decisions are rarely about selecting the most popular provider; instead, they depend on an organization's existing software infrastructure, budget constraints, scaling demands, and compliance requirements. For example, an enterprise heavily invested in Microsoft 365 natively aligns with Azure, while a fast-scaling startup or a high-performance machine learning research facility benefits more from AWS or GCP, respectively.

Acting as a Cloud Solutions Consultant transformed my approach to technology. I learned to analyze system challenges through a business-oriented lens, weighing trade-offs to deliver practical recommendations rather than relying on personal bias. Furthermore, documenting this multi-cloud exploration within my GitHub Cloud Computing Portfolio has significantly improved my technical writing, structural organization, and command of Markdown. Maintaining a well-documented portfolio allows me to showcase applied cloud architecture concepts, system monitoring skills, and analytical problem-solving capabilities effectively to future academic and professional audiences.
