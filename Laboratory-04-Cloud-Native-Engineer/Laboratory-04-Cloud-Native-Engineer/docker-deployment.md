# Docker Deployment & Container Lifecycle

## Lifecycle Commands Reference

* `docker ps`: Lists all active, currently running containers and their associated details (IDs, images, ports).
* `docker stop my-nginx`: Gracefully halts the execution of the running `my-nginx` container without deleting its data.
* `docker ps -a`: Displays a complete list of all containers on the host, including stopped or exited containers.
* `docker rm my-nginx`: Permanently deletes the stopped `my-nginx` container from the host system.
